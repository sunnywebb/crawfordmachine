From Fusion 360 Model to Real Part: How We Program CNC Toolpaths

Crawford Machine · October 2026

A lot of people ask how a drawing on a screen turns into a finished steel part. At Crawford Machine in Titusville, PA, that process runs through Fusion 360, a CAD/CAM program we use to model parts and program our Haas CNC mill and lathe. Here is what it looks like on a typical job.

Step 1: Model the part

We start with a sketch of the part, whether that is a customer drawing, a worn sample, or a napkin sketch with a few dimensions. In Fusion 360 we build a 3D model of the part with every hole, slot, thread, and radius in the right place. Simple parts take minutes. Complex parts take longer, but the model lets us catch problems before any metal gets cut.

Step 2: Draw the CAM toolpaths

CAM stands for computer-aided manufacturing. In the CAM workspace we tell the software which tools to use (end mills, drills, taps, boring bars), how fast to spin them, how deep to cut, and the path each tool follows across the stock. Fusion 360 simulates the whole operation so we can watch the virtual part being cut and confirm nothing collides.

Step 3: Post the program to the machine

Once the toolpaths look right, Fusion 360 generates G-code for our Haas CNC. We load the program, set up the stock in the vise or chuck, touch off the tools, and run the first part.

Step 4: Inspect and run

We measure the first part against the model with micrometers, calipers, and gauges. If it checks out, we run the rest of the order. If something is off by a thousandth, we adjust the program and run it again.

CNC machining with CAD/CAM gives us repeatability. The tenth part matches the first part, and if you need more next year, the program is ready to run again.
